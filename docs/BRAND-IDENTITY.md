## 1. Brand Philosophy: The Free & Open Windows Standard

WinCraft represents an independent, community-first evolution in Windows tuning software. While proprietary utilities and commercial optimizers lock basic controls behind subscriptions and paywalls, WinCraft exists to ensure that **every Windows user has access to a fast, private, and bloatware-free operating system at zero cost**.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                 The WinCraft Promise                                   │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ • 100% Free Forever: No Pro tiers, no paywalled buttons, no trial periods.            │
│ • 100% Transparent: Open-source Rust & TypeScript; inspect every registry key.        │
│ • 100% Reversible: Automatic pre-write snapshots and Volume Shadow Copy restore points.│
│ • 0% Servicing Breakage: Never corrupts WinSxS, DISM, or monthly Windows Updates.      │
│ • Community-Driven: Built with and for the global PC community.                        │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 2. Visual Identity & Design System

### 2.1 Logo & Iconography
- **Primary Mark:** The modern stylized WinCraft Emblem (a clean geometric craft shield with cyber ember accents).
- **Icon Set:** Crisp SVG vector icons optimized for 16px, 32px, 48px, 128px, and 256px displays across all scale factors (100% to 250% DPI).

### 2.2 UI Color Tokens (Graphite Ember & Modern Dark)
- **Background Base:** `bg-surface-base` (`#0f0f11`)
- **Surface Elevated:** `bg-surface-elevated` (`#18181b`)
- **Accent Primary:** `accent-primary` (`#f97316` / Ember Orange)
- **Accent Secondary:** `accent-secondary` (`#06b6d4` / Cyan Pulse)
- **Status Success:** `status-success` (`#22c55e` / Emerald)
- **Status Danger:** `status-danger` (`#ef4444` / Crimson)

## 3. Communication Guidelines

When communicating about WinCraft:
- **Tone:** Technical, honest, empowering, and respectful of user intelligence.
- **Evidence-Based:** Avoid unsubstantiated "300% FPS BOOST" claims. Quote exact measured numbers, frame-time variance reductions, and DPC latency statistics.
- **Inclusivity:** Support all 6 major languages (`en`, `it`, `fr`, `es`, `de`, `pt`) with culturally accurate localization.

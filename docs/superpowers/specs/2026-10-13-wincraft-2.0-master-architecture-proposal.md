## 1. Executive Summary & Product Vision

### 1.1 The Core Problem: The Degradation of the Windows User Experience
Over the past decade, Windows has shifted from a lean, responsive operating system focused on user agency (exemplified by **Windows 7**) to a bloated service delivery platform loaded with:
- **Pervasive Background Telemetry & Autologgers:** Continuous Event Tracing for Windows (ETW) circular logging, diagnostics tracking, telemetry uploads, and user behavior profiling.
- **Aggressive Cloud & Web Injections:** Bing search API roundtrips inside local File Explorer and Start Menu, web widget daemons, MSN News feeds, and dynamic promotional app injections.
- **Unchecked Process & Memory Sprawl:** On Windows 11, clean boots frequently spin up **150–220 background processes** and consume **3.5–5.2 GB of RAM at idle**, compared to Windows 7's **35–45 processes** and **~600 MB RAM**.
- **Artificial UI Latency & Micro-Stutter:** Built-in UI delays (`MenuShowDelay = 400ms`), nested modern context menus, background UWP/XAML broker wakelocks, and unoptimized DPC/ISR interrupt queue processing.
- **Modern Hardware Underutilization:** High-end multi-core CPUs (AMD Ryzen 3D V-Cache, Intel P/E hybrid architectures) frequently experience thread mis-scheduling, cache latency spikes, and frame time variance in real-time gaming and audio production.

### 1.2 The Failure of Custom ISOs & Playbooks (*AtlasOS, ReviOS, Tiny11*)
Frustrated by this bloat, millions of users turn to custom ISOs and stripping scripts. However, these tools introduce critical systemic flaws:
1. **Destructive Component Stripping:** They rip out `WinSxS`, Windows Update, Windows Defender, BitLocker, or core servicing stacks, making monthly cumulative security updates impossible.
2. **Zero Reversibility:** Once a stripped ISO is installed, fixing a broken subsystem requires a **full Windows reinstallation**.
3. **Enterprise & Game Integrity Incompatibility:** Stripped Windows builds fail enterprise compliance audits, Microsoft Intune enrollment, and kernel game integrity integrity checks (Game Security, Easy Game Integrity, Game Guard).

### 1.3 The WinCraft 2.0 Mission
**WinCraft 2.0 delivers the pure, instantaneous responsiveness and 100% privacy of Windows 7 on modern Windows 11 (24H2/23H2) and Windows 10, without destructive ISO modifications.**

Every optimization is:
- **100% Non-Destructive & Servicing-Safe:** Windows Update, DISM component store, DirectX 12 Ultimate, and system integrity remain completely functional.
- **100% Reversible:** Backed by transactional registry snapshots, AppX package journals, service state records, and pre-flight Volume Shadow Copy (VSS) restore points.
- **Scientifically Measured:** Every tweak is categorized by empirical evidence (`Measured`, `Modest`, `Neutral`), effect timing (`Immediate`, `SignOut`, `Restart`), and documented risk factors.

### 2.2 Deep Subsystem Bottleneck Analysis

#### A. The `SvcHostSplitThresholdInKB` Phenomenon
Starting in Windows 10 (1703), Microsoft introduced service host splitting for all systems with >3.5 GB of RAM. While intended to isolate service crashes, it results in **massive process count inflation** (often 80+ extra processes), increasing page table overhead, memory fragmentation, and context-switching overhead on CPU schedulers. WinCraft 2.0 exposes a safe, configurable threshold control to group non-critical system services while maintaining stability.

#### B. Interrupt & DPC Latency Spikes
Micro-stutters during high-refresh-rate gaming and real-time Digital Audio Workstation (DAW) playback are caused by Deferred Procedure Call (DPC) spikes. Key contributors include:
1. `NetworkThrottlingIndex` dynamically throttling non-multimedia network packets to prioritize Windows Media Player.
2. `SystemResponsiveness` reserving 20% of CPU cycles for background system tasks during multimedia playback.
3. Telemetry autologgers and Game DVR background capture pipelines interrupting CPU cores.
WinCraft 2.0 optimizes the Multimedia Class Scheduler Service (MMCSS) and network throttling parameters to achieve sub-50µs DPC latency.

#### C. Asymmetric Multicore Architectures (AMD X3D & Intel Hybrid)
- **AMD Ryzen 7000X3D / 9000X3D Series:** CPUs feature dual Core Complex Dies (CCDs) — CCD0 with 3D V-Cache (high L3, slightly lower clock) and CCD1 with standard cache (higher clock). Default Windows scheduling often leaks game threads onto CCD1, introducing high inter-die Infinity Fabric latency.
- **Intel 12th–15th Gen Hybrid:** Windows Thread Director frequently misallocates background utilities to Performance Cores (P-Cores) or spills high-throughput rendering threads onto Efficiency Cores (E-Cores).
WinCraft 2.0 dynamically manages core affinity and process priority rules to eliminate cross-die penalties.

### Pillar I: 100% Privacy & Zero-Telemetry Hardening

WinCraft 2.0 achieves complete privacy hardening across all Windows sub-layers without breaking Windows Update:

1. **Universal 7-Location Telemetry Sweep:**
   - `HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection` (`AllowTelemetry = 0`, `MaxTelemetryAllowed = 0`)
   - `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\DataCollection` (`AllowTelemetry = 0`)
   - `HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Policies\DataCollection` (`AllowTelemetry = 0`)
   - `HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection` (`CommercialDataOptIn = 0`)
   - `HKCU\Software\Microsoft\Windows\CurrentVersion\Diagnostics\DiagTrack` (`ShowDiagTrackUi = 0`)
   - `HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection` (`DisableDiagnosticDataViewer = 1`)
   - `HKLM\SOFTWARE\Policies\Microsoft\Windows\DataCollection` (`DoNotShowFeedbackNotifications = 1`)

2. **Autologger ETW Session Teardown:**
   - Disables continuous circular disk logging for telemetry ETW sessions:
     - `AutoLogger-Diagtrack-Listener`
     - `SQMLogger`
     - `AITEventLog`
     - `DiagLog`
     - `WiFiSession`

3. **Core Telemetry Services Lockdown:**
   - `DiagTrack` (Connected User Experiences and Telemetry) → Disabled
   - `dmwappushservice` (Device Management Wireless Application Protocol Push) → Disabled
   - `WerSvc` (Windows Error Reporting Service) → Disabled or Manual
   - `diagsvc` (Diagnostic Execution Service) → Disabled

4. **AI & Modern Windows 11 Data Collection Lockdown:**
   - **Windows Copilot:** `HKCU` & `HKLM` Policy `TurnOffWindowsCopilot = 1`
   - **Windows Recall (Copilot AI Snapshots):** `DisableAIDataAnalysis = 1`, `AllowRecall = 0`
   - **Click to Do & AI Actions:** Group policy enforcement to disable background screen indexing.
   - **Cortana & Voice Personalization:** `AllowCortana = 0`, `InputPersonalization\RestrictImplicitInkCollection = 1`

5. **Behavioral Tracking & Advertising ID:**
   - Disables Windows Advertising ID across all accounts (`SubscribedContent-338387Enabled = 0`, `AdvertisingInfo\Enabled = 0`).
   - Disables Activity History & Timeline cloud sync (`EnableActivityFeed = 0`, `PublishUserActivities = 0`, `UploadUserActivities = 0`).
   - Disables Inking and Typing personalization data harvest (`HarvestContacts = 0`).
   - Disables Windows Location Services & Geolocation tracking (`lfsvc` disabled, `SensorPermission = 0`).

6. **Edge & Web Telemetry Lockdown:**
   - Disables Microsoft Edge Startup Boost and background extensions daemon (`StartupBoostEnabled = 0`, `BackgroundModeEnabled = 0`).
   - Disables Edge diagnostic data transmission (`MetricsReportingEnabled = 0`, `SendSiteInfoToImproveServices = 0`).

### Pillar IV: Low-Latency Kernel, CPU & Memory Optimization

1. **`SvcHostSplitThresholdInKB` Optimization:**
   - Exposes a safe toggle to group Windows background services into consolidated `svchost.exe` pools, reducing idle process counts from ~180 down to ~70 and cutting context-switching overhead.

2. **DPC & Interrupt Latency Tuning:**
   - **Multimedia Class Scheduler Service (MMCSS):**
     - `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\NetworkThrottlingIndex = 0xFFFFFFFF` (disables network packet throttling during gaming/audio).
     - `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\SystemResponsiveness = 0` (dedicates 100% CPU priority to foreground applications).
   - **Game DVR Overhead Elimination:** Completely disables Game DVR background video capture buffers and kernel polling (`AppCaptureEnabled = 0`, `GameDVR_Enabled = 0`).

3. **Network Latency & TCP/IP Optimization:**
   - **TCPNoDelay & TcpAckFrequency:** Disables Nagle's algorithm on active network adapters (`TCPNoDelay = 1`, `TcpAckFrequency = 1`), dispatching small packets immediately to eliminate micro-stutter in competitive online gaming.

4. **Dynamic CPU Core Thread Director & Cache Steering:**
   - **AMD Ryzen 3D V-Cache (X3D) Steering:** Automatically pins gaming threads to high-cache CCD0 (3D V-Cache) and background worker processes to frequency-focused CCD1, eliminating inter-die Infinity Fabric latency spikes.
   - **Intel 12th–15th Gen Hybrid Steering:** Automatically routes active gaming and DAW processes to high-throughput P-Cores while isolating background utilities to E-Cores.

5. **Memory & Working Set Optimization:**
   - **Standby List Memory Cleaner:** Purges cached standby memory pages without thrashing active process working sets.
   - **SysMain (SuperFetch) Tuning:** Configures SysMain appropriately for high-speed Gen4/Gen5 NVMe SSDs to prevent unnecessary background disk thrashing.

6. **File System & Storage Optimization:**
   - **Disable NTFS 8.3 Name Creation:** `NtfsDisable8dot3NameCreation = 1` eliminates legacy DOS 8.3 short filename generation, accelerating directory enumeration on large folders.
   - **Disable NTFS Last Access Time Updates:** `NtfsDisableLastAccess = 1` eliminates unnecessary disk write operations on every file read.

### Pillar VI: Non-Destructive Safety & Transactional Rollback

WinCraft 2.0 guarantees that every optimization is safe, auditable, and 100% reversible:

1. **The "Zero-Brick" Invariant:**
   - WinCraft never deletes `WinSxS`, never corrupts `DISM /Online /Cleanup-Image`, and never disables core Windows security services irreversibly.
   - Windows Update remains 100% operational for all monthly security patches.

2. **Pre-Flight Volume Shadow Copy (VSS) Restore Points:**
   - Automatically creates a native Windows System Restore Point via WMI `SRSetRestorePoint` before executing any elevated system modifications.

3. **Transactional Change Ledger:**
   - Every registry write, service state modification, scheduled task change, and AppX package removal is recorded in `%APPDATA%\WinCraft\history.json` with its original value, type, and timestamp.
   - 1-click single-tweak or full-batch rollback restores the exact prior state.

4. **Standalone Offline Emergency Recovery Script:**
   - WinCraft automatically exports an offline `wincraft-emergency-undo.bat` script that can be executed from Windows Recovery Environment (WinRE) Command Prompt if the desktop UI is ever inaccessible.

5. **Exportable/Importable Profile Bundles:**
   - Export your complete system tuning configuration as a lightweight, signed `.wincraft.json` profile for seamless deployment across multiple PCs.

### 5.1 Strict Quality Gates & Verification Criteria
1. **Type Safety & IPC Parity:** `tsc --noEmit` must pass with 0 errors; every IPC command must match between `src-tauri/src/ipc_commands.rs`, `lib.rs`, and frontend callers.
2. **Localization Invariants:** 100% key and placeholder parity across all 6 supported locales (`en`, `it`, `fr`, `es`, `de`, `pt-PT`) with zero missing or unreviewed strings (`audit-i18n.mjs`).
3. **Public Claim Synchronicity:** `scripts/check-public-counts.mjs` must assert exact catalog counts across all documentation and UI components.
4. **Safety Verification:** Pre-flight restore point creation and change ledger rollback must be verified on both elevated and non-elevated execution paths.
